# Saved MOTDs

Finished server messages live here as plain `.txt` files — one file per server/variant.
Each file is exactly what gets pasted into the RCON welcome-message editor.

- Open one in the builder with **Open…**, edit it, then **Download .txt** and commit it back here.
- `npm test` validates every `.txt` in this folder, so a broken MOTD fails CI before it reaches a server.
